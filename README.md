# AIEAT – บันทึกน้ำหนักและแคลอรี่เพื่อลดน้ำหนัก

เว็บแอปสำหรับใช้บนมือถือ ใช้บันทึกน้ำหนักเช้าและเย็น บันทึกอาหาร 3 มื้อกับของกินระหว่างวัน และคำนวณแคลอรี่เทียบกับเป้าลดน้ำหนัก
ข้อมูลทั้งหมดเก็บอยู่ในเบราว์เซอร์ของเครื่องที่ใช้งาน (IndexedDB) ไม่ต้องมีเซิร์ฟเวอร์

## เฟส 1 (ปัจจุบัน)
- ตั้งค่าโปรไฟล์ แล้วคำนวณ BMR (Mifflin-St Jeor), TDEE และเป้าแคลต่อวันตามความเร็วที่เลือก (0.25, 0.5 หรือ 0.75 กก./สัปดาห์) โดยเป้าไม่ต่ำกว่า 1,200/1,500 kcal
- บันทึกน้ำหนักเช้าและเย็น: เทียบกับเมื่อวาน เฉลี่ยน้ำหนักเช้า 7 วัน น้ำหนักที่ลดไปแล้ว น้ำหนักที่เหลือ และ BMI (เกณฑ์เอเชีย)
- บันทึกอาหาร 4 หมวด: ฐานข้อมูลอาหารไทยประมาณ 150 รายการ ค้นหาได้ มีเมนูล่าสุด เพิ่มเมนูของฉันได้ และปรับจำนวนทีละ 0.5
- หน้าวันนี้: วงแหวนแสดงแคลที่เหลือหรือเกินเป้า และแคลแยกตามมื้อ เลื่อนดูวันก่อนหน้าได้
- Export/Import ข้อมูลเป็นไฟล์ JSON

## รันบนเครื่อง
```bash
npm install
npm run dev
```

## Deploy (GitHub Pages)
เมื่อ push ขึ้น `main` workflow `.github/workflows/deploy.yml` จะ build และ deploy ให้อัตโนมัติ
ต้องเปิดใช้ก่อนหนึ่งครั้งที่ Settings → Pages → Source: **GitHub Actions**

## แผนถัดไป
- เฟส 2: กราฟน้ำหนักและแคล หน้าวิเคราะห์รายสัปดาห์ คาดการณ์วันถึงเป้า และติดตั้งเป็นแอปบนมือถือ (PWA)
- เฟส 3: ใช้ AI ประเมินแคลจากข้อความหรือรูป และซิงก์ข้อมูลข้ามเครื่อง
